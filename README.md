# knot

DES204 Tangible Interaction & Interfaces (2026 가을) 프로젝트.
AI와 하던 프로젝트를 줄을 묶어 끝내는 탠저블 인터페이스.

## 인터랙션
- 카드 꽂기: 프로젝트 폴더 생성, 대화 시작
- 대화 중: 줄 아래 곡면 LED가 노랗게 일렁임
- 슬라이더로 빼기: 잠깐 멈춤, 다른 카드로 전환
- 줄 묶기: 끝. 카드에 (──) 구멍이 뚫려 나오고 폴더가 닫힘
- 뚫린 카드를 옆면 핀에 걸기: 그 프로젝트의 결정 흐름(브랜치맵)을 보기만 함

## 폴더
- `blender/knot_device.blend` — 작업 파일 (씬 `MOON`)
- `web/knot_device.glb` — 웹 뷰어용 모델 (몸체 vertex color = LED 마스크)
- `renders/white/` — 흰 배경 최신 렌더
- `renders/dark_slides/` — 11/23 보고 장표에 쓴 어두운 배경 렌더
