# 근거 논문

첫 장 캡처는 같은 폴더의 `<arXiv id>-01.png`.

## AI는 끝난 맥락을 놓지 못한다
- PersistBench: When Should Long-Term Memories Be Forgotten by LLMs? (arXiv 2602.01146, 2026) — 한 분야의 기억이 상관없는 새 질문에 끼어든다
- STALE: Can LLM Agents Know When Their Memories Are No Longer Valid? (arXiv 2605.06527, 2026) — 기억이 낡았다는 걸 잘 알아채지 못한다
- Unable to Forget: Proactive Interference Reveals Working Memory Limits in LLMs Beyond Context Length (arXiv 2506.08184, 2025) — 지난 정보가 지금 정보를 가린다
- LLMs Get Lost in Multi-Turn Conversation (Laban et al., ICLR 2026, arXiv 2505.06120) — 여러 턴에서 평균 39% 하락, 잘못 든 길에서 못 돌아온다
- Context Length Alone Hurts LLM Performance Despite Perfect Retrieval (arXiv 2510.05381, 2025) — 길이만으로 13.9~85% 하락

## AI와 한 작업은 내 것 같지 않다
- The AI Ghostwriter Effect (Draxler et al., TOCHI 2024, arXiv 2303.03283)
- The HaLLMark Effect (Hoque et al., CHI 2024, arXiv 2311.13057) — 과정 시각화가 소유감을 지켰다
- Ownership in AI-Assisted Everyday Tasks (arXiv 2609.20658, 2026) — 상호작용 기록을 보여주면 소유감이 강해지는지는 열린 질문

## 끝은 사용자가 낼 때 닫힌다
- "Death" of a Chatbot: Investigating and Designing Toward Psychologically Safe Endings for Human-AI Relationships (arXiv 2602.07193, 2026)
- Before Bringing It Up: When and How AI Companions Should Use Memory (arXiv 2610.09470, 2026)

## 원문 안 받은 것 (참고)
- Design for Rituals of Letting Go (Sas et al., TOCHI 2016) — 디지털 폐기를 몸으로 하는 의식으로 설계
- AI Never Forgets: Users' Perceptions of AI Memory and ChatGPT's Memory Feature (CHI 2026)
